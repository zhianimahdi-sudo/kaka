# کارپوشهٔ جامع کمیسیون فنی — بازطراحی کامل از صفر

کارپوشهٔ اکسل فارسی (راست‌به‌چپ، ریال، تقویم شمسی) با ۱۰ شیت، موتور محاسبهٔ فرمولی و
داشبورد مدیریتی — طراحی‌شده از صفر، با آزمون خودکار صحت محاسبات.

| فایل | توضیح |
|---|---|
| **`کمیسیون فنی.xlsx`** | فایل نهایی و آمادهٔ استفاده (۱۰ شیت، ۵٬۳۰۰+ فرمول زنده، ۴ نمودار) |
| `docs/design-blueprint.md` | نقشهٔ طراحی و وضعیت ساخت |
| `docs/formula-map.md` | نقشهٔ فرمول‌ها و نام‌های محدوده (خودکار از فایل) |
| `docs/values-reference.md` | مقادیر مرجع دادهٔ نمونه برای آزمون رگرسیون (خودکار) |
| `docs/maintenance-guide.md` | راهنمای تغییر پارامترها، افزودن رکورد و توسعهٔ فایل |

## شیت‌ها

| # | شیت | وظیفه |
|---|---|---|
| ۱ | راهنما | صفحهٔ خانه: نقشهٔ شیت‌ها، گام‌های استفاده، راهنمای رنگ‌ها و شاخص‌های زنده |
| ۲ | تنظیمات | تنها منبع پارامترها: مالیات، کف/سقف کمیسیون، مهلت پرداخت، درصد سهم پیش‌فرض، هدف سالانه، پله‌های نرخ |
| ۳ | فهرست‌ها | بانک ۷ فهرست مرجع با جدول رسمی و محدودهٔ پویا |
| ۴ | اعضا | پرسنل + عملکرد زندهٔ هر نفر (`COUNTIFS` / `SUMIFS` / آخرین فعالیت) |
| ۵ | تراکنش‌ها | دفتر پرونده‌ها: ۱۰ ستون ورودی + ۱۶ ستون محاسبهٔ خودکار، برای ۳۰۰ ردیف |
| ۶ | ماشین‌حساب | سناریوسازی یک‌موردی در ۱۳ گام شفاف، بدون ساخت رکورد |
| ۷ | گزارش‌ها | ۴ بلوک تجمیعی: اعضا، روند ماهانه، انواع خدمات، وضعیت‌ها |
| ۸ | داشبورد | ۸ کارت شاخص با فیلتر سال/ماه + ۴ نمودار (ستونی، خطی، دوناتی، ترکیبی) |
| ۹ | کنترل کیفیت | ۱۲ آزمون خودکار صحت داده و تطبیق جمع‌ها با نتیجهٔ ✅/❌ |
| ۱۰ | تقویم | پل تبدیل تاریخ میلادی ↔ شمسی، ۵٬۱۱۴ روز (۱۴۰۱ تا ۱۴۱۵) |

## زنجیرهٔ محاسبه

```
مبلغ کارشناسی × ضریب خدمت = مبلغ مبنا
مبلغ مبنا → ضریب پله (LOOKUP) → نرخ پایهٔ خدمت × ضریب پله = نرخ مؤثر
مبلغ مبنا × نرخ مؤثر = کمیسیون خام
کمیسیون خام → کف/سقف (و صفر برای وضعیت ابطال) = کمیسیون تعدیل‌شده
کمیسیون تعدیل‌شده × نرخ مالیات = مالیات و عوارض
تعدیل‌شده + مالیات = جمع با مالیات
جمع با مالیات × درصد سهم = سهم عضو · باقی‌مانده = سهم شرکت
```

## اجرای ابزارها

```bash
pip install --target ./pylibs openpyxl              # وابستگی محلی

PYTHONPATH=./pylibs python3 build/build_workbook.py --out "کمیسیون فنی.xlsx"   # ساخت کارپوشه
PYTHONPATH=./pylibs python3 build/validate_output.py "کمیسیون فنی.xlsx"        # اعتبارسنجی ساختار
PYTHONPATH=./pylibs python3 build/engine_check.py "کمیسیون فنی.xlsx"          # آزمون موتور محاسبه (نیاز به pycel)
PYTHONPATH=./pylibs python3 build/make_docs.py "کمیسیون فنی.xlsx"             # تولید مستندات از فایل
python3 tools/jalali.py                                                        # صحت‌سنجی تبدیل تاریخ
PYTHONPATH=./pylibs python3 tools/inspect_workbook.py <file.xlsx>              # استخراج منطق هر فایل اکسل
```

## آزمون‌ها

| ابزار | چه چیزی را تضمین می‌کند |
|---|---|
| `build/validate_output.py` | هر ارجاع ساخت‌یافته به ستون موجود اشاره می‌کند · پرانتزها متوازن‌اند · جداول سالم‌اند · همهٔ شیت‌ها RTL هستند · ۴۶ نام محدوده معتبرند |
| `build/engine_check.py` | ۲۶۲ بررسی عددی: خروجی موتور فرمول اکسل در برابر مدل مرجع مستقل پایتون — **صفر اختلاف** |
| `tools/jalali.py` | ۷ تست تبدیل تاریخ میلادی ↔ شمسی |
| شیت کنترل کیفیت | ۱۲ آزمون زندهٔ درون فایل (تکرار، ناقص‌بودن، تاریخ نامعتبر، تطبیق جمع‌ها، سرسیدها) |

## نکات فنی کلیدی

- **صفر عدد جادویی:** همهٔ ضرایب و سقف‌ها در شیت «تنظیمات» با نام محدوده تعریف شده‌اند.
- **محدوده‌های پویا:** ۲۵ نام با `OFFSET`+`COUNTA` ساخته شده‌اند؛ افزودن گزینهٔ جدید به فهرست‌ها
  یا عضو جدید، خودکار در کشویی‌ها و گزارش‌ها ظاهر می‌شود.
- **تاریخ شمسی واقعی:** تاریخ‌ها متن `1405/07/22` هستند و از جدول تقویم به سری میلادی نگاشت می‌شوند؛
  مهلت پرداخت و تشخیص سرسید با محاسبهٔ سری انجام می‌شود.
- **پایداری در برابر خالی‌بودن:** همهٔ فرمول‌ها با `IFERROR`/`IF` محافظت شده‌اند؛ فایل تازه هم بدون خطا است.
- **بازمحاسبهٔ خودکار:** فایل با `fullCalcOnLoad` ذخیره می‌شود تا اعداد در اولین باز شدن محاسبه شوند.
