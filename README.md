# داشبورد قراردادهای مهر خلیج فارس — نسخهٔ ۴٫۱٫۰

یک برنامهٔ دسکتاپ تک‌فایلی (Python + PyQt5) برای دیدن وضعیت قراردادها و
به‌روزرسانی خودکار همان کتاب کار از خروجی سامانه. همهٔ داده‌ها در ویندوز داخل
پوشهٔ **`D:\DATANEW`** نگهداری می‌شوند و برنامه هیچ نیازی به MySQL، رمز
دیتابیس یا سرویس جداگانه ندارد.

نسخهٔ ۴ از صفر بازنویسی شد: دیتابیس داخلی SQLite، حذف کامل MySQL، حذف
فایل‌های جانبی `dashboard.html` و `mehr_optimized.txt`، و یک دکمه برای
به‌روزرسانی از «فایل ۰۱».

---

## ۱) شروع سریع (ویندوز)

1. Python 3.9 یا بالاتر را از <https://www.python.org/downloads/> نصب کنید و
   هنگام نصب گزینهٔ **Add Python to PATH** را فعال بگذارید.
2. فایل `run_windows.bat` را دوبار کلیک کنید. بار اول پیش‌نیازها
   (`PyQt5` و `openpyxl`) خودکار نصب می‌شوند.
3. برنامه با داشبورد خالی باز می‌شود. یکی از این دو کار را بکنید:
   - **«به‌روزرسانی از فایل ۰۱»** (دکمهٔ بنفش بالای صفحه): فایل خروجی سامانه
     (همان فایلی که ستون `Sub Project` دارد) را انتخاب کنید. اگر کتاب کاری
     در دیتابیس نباشد، برنامه خودش کتاب کار پایه را از همان فایل می‌سازد.
   - یا در صفحهٔ **تنظیمات**، «بارگذاری کتاب کار…» را بزنید و فایل
     `F.O.C(Mehr).xlsx` (دارای شیت `colorcode`) را انتخاب کنید.

پوشهٔ `D:\DATANEW` در اولین اجرا خودکار ساخته می‌شود. اگر درایو `D:` وجود
نداشته باشد، برنامه پوشهٔ `DATANEW` را کنار خودِ فایل برنامه می‌سازد و همان را
استفاده می‌کند؛ مسیر واقعی همیشه در صفحهٔ «تنظیمات» و ابتدای `logs/mehr.log`
نوشته می‌شود.

## ۲) ساختار `D:\DATANEW`

```
D:\DATANEW\
├─ database\mehr.db          دیتابیس داخلی (SQLite): کتاب کارها، قراردادها، یادداشت‌ها، نشان‌ها، تنظیمات
├─ workbooks\                نسخهٔ اصلی هر کتاب کاری که بارگذاری/ساخته شده
├─ output\                   نسخهٔ به‌روزشدهٔ ساخته‌شده از «فایل ۰۱»
├─ exports\                  خروجی اکسل قراردادها و گزارش مدیریتی
├─ backup\                   پشتیبان دیتابیس (قبل از «ساخت دیتابیس از صفر»)
└─ logs\
   ├─ mehr.log               گزارش کارهای برنامه
   └─ errors.log             خطاهای کامل برای پیگیری
```

نکته‌ها:

- فایل اکسل شما **هرگز بازنویسی نمی‌شود**؛ نسخهٔ به‌روز همیشه با نام تازه در
  `output\` ساخته می‌شود.
- `Contract-Info-Report.xlsx` و `02.xlsx` دست‌نخورده می‌مانند؛ برنامه فقط
  فایل ۰۱ را می‌خواند و کتاب کار خودش را می‌سازد.
- هیچ داده‌ای بیرون از `D:\DATANEW` نوشته نمی‌شود (به‌جز فایل‌های موقتی
  سیستم برای بازمحاسبهٔ اکسل روی ویندوز).

برای تغییر محل داده (مثلاً در آزمون یا روی درایو دیگر) دو راه هست:

```bat
python mehr_dashboard_qt.py --data-dir "E:\DATANEW"
set MEHR_DATA_DIR=E:\DATANEW
```

## ۳) صفحه‌های برنامه

| صفحه | چه چیزی دارد |
|---|---|
| **داشبورد** | کارت گرادیانی درصد پیشرفت با حلقه و نوار، چهار کارت آمار، ۸ کارت وضعیت با نوار سهم، توزیع نوع قرارداد، بیشترین اسناد باز، وضعیت قرارداد در سامانه |
| **قراردادها** | جدول ۱٬۱۸۷ قراردادی با جستجو (شماره، شرکت، موضوع، شناسه، نوع)، فیلتر (وضعیت‌ها، اسناد باز، دارای شرح مشکل، نشان‌شده)، جزئیات هر قرارداد، یادداشت، نشان، باز کردن PDF |
| **گزارش** | خلاصهٔ مدیریتی + خروجی اکسل قراردادها + گزارش چهارشیتی + چاپ/ذخیرهٔ PDF |
| **تنظیمات** | محل داده‌ها، ساخت دیتابیس از صفر، فهرست کتاب کارهای ذخیره‌شده، بارگذاری کتاب کار، پوشهٔ PDF، پوستهٔ روشن/تیره، اندازهٔ قلم |

### دکمهٔ «به‌روزرسانی از فایل ۰۱»

1. فایل ۰۱ (خروجی سامانه با ستون `Sub Project`) را انتخاب می‌کنید.
2. برنامه فقط ردیف‌های **«اجرا - مهر»** را برمی‌دارد و ستون‌های `L` تا `AJ`
   را در شیت «خروجی کندو» می‌نشاند.
3. ستون‌های محاسباتی (الزام‌ها `AL..BH`، ترکیب‌ها `BK..CG`، جمع‌ها) و
   شیت `colorcode` از همان فرمول‌های خودِ کتاب کار محاسبه می‌شوند.
4. نسخهٔ تازه با نام `…-به‌روز-YYYYmmdd-HHMM.xlsx` در `output\` ذخیره و در
   دیتابیس ثبت می‌شود.
5. پیش از ذخیره، خروجی دوباره خوانده می‌شود؛ اگر تعداد علامت‌ها یا درصد صفر
   شود، آن فایل جای دادهٔ فعلی را نمی‌گیرد و برنامه خطای روشن می‌دهد.

اعداد کنترل روی دادهٔ واقعی (`01_real.xlsx`):

- ۱٬۱۸۷ قرارداد، درصد پیشرفت **۹۶٫۲۸٪**، **۷۰۳** علامت `M`
- کارت‌ها: تحویل موقت ۹، ماقبل قطعی ۱۰، بالانس متریال ۳۱، صورت‌وضعیت قطعی ۱۶،
  مفاصاحساب بیمه ۳۲، اقرارنامه ۳۰، تحویل قطعی ۳۸، تسویهٔ مالی ۶۴ (جمع ۲۳۰)

## ۴) خط فرمان

```bat
python mehr_dashboard_qt.py                       :: پنجرهٔ برنامه
python mehr_dashboard_qt.py --version             :: نسخه
python mehr_dashboard_qt.py --check               :: بررسی داده‌ها بدون پنجره
python mehr_dashboard_qt.py --import-xlsx "D:\...\F.O.C(Mehr).xlsx"
python mehr_dashboard_qt.py --update-from  "D:\...\Contract-Info-Report.xlsx"
python mehr_dashboard_qt.py --data-dir "E:\DATANEW"
```

- `--check` اگر هنوز هیچ کتاب کاری در دیتابیس نباشد با کد ۱ برمی‌گردد.
- `--update-from` نسخهٔ به‌روز را در `output\` می‌سازد و اگر تأیید شود در
  دیتابیس ذخیره می‌کند.

## ۷) تغییرات نسخه‌ها

- **۴٫۱٫۰ (این نسخه):** ظاهر تازه (کارت گرادیانی درصد، حلقهٔ پیشرفت، کارت‌های
  وضعیت با نوار سهم، نمودارهای میله‌ای گرد)، صفحهٔ شروع راهنما وقتی هنوز
  کتاب کاری نیست، و **اصلاح ریشه‌ای کارت‌های صفر**: کتاب کارهایی که ستون‌های
  مدرکشان فرمول است و مقدار ذخیره‌شده ندارند، حالا از شیت «خروجی کندو»
  محاسبه می‌شوند؛ داده‌های قدیمی دیتابیس هم در اولین بازخوانی خودکار ترمیم
  می‌شوند. درصد با جداکنندهٔ فارسی و رقم‌های فارسی نمایش داده می‌شود.
- **۴٫۰٫۰:** بازنویسی کامل از صفر؛ دیتابیس SQLite در
  `D:\DATANEW`؛ حذف MySQL و رمز/پورت؛ حذف فایل ۰۲؛ حذف `dashboard.html` و
  `mehr_optimized.txt`؛ یک دکمه برای به‌روزرسانی از فایل ۰۱؛ ساخت خودکار
  کتاب کار پایه؛ کنترل نهایی اعداد و جلوگیری از صفرشدن داشبورد؛ حفظ ردیف‌های
  خارج از «اجرا - مهر» به همان مقدار قبلی.
- **۳٫۶٫۱:** جلوگیری از صفر شدن داشبورد، ساخت خودکار شیت خروجی، تشخیص خطای
  پورت/رمز MySQL.
- **۳٫۶٫۰:** بازسازی دیتابیس مرکزی از صفر و محاسبه داخل «خروجی کندو».
- **۳٫۵٫x:** حذف فایل ۰۲، عدم بازنویسی کتاب کار کاربر، جایگزینی `M` به‌جای
  ۰/۱، ۲۳ ستون مدرک، حفظ فرمول‌های colorcode.
- **۳٫۲٫۰ تا ۳٫۴٫x:** تشخیص خودکار PDF، به‌روزرسانی از فایل ۰۱، حذف
  وابستگی به فایل ۰۲، اعداد فقط از کتاب کار واقعی.

## ۸) پیش‌نیازها

- ویندوز ۱۰/۱۱ (یا لینوکس برای آزمون)
- Python 3.9+
- `PyQt5>=5.15` و `openpyxl>=3.0` (نصب: `pip install -r requirements.txt`)
- مایکروسافت اکسل نصب باشد بهتر است: برنامه برای بازمحاسبهٔ فرمول‌های پیچیده
  کتاب کار از Excel استفاده می‌کند؛ اگر نبود، مقدارهای محاسبه‌شده را خودش
  جای فرمول‌ها می‌نویسد تا داشبورد خالی نماند.
