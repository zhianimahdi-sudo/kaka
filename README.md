# پروژهٔ بازطراحی فایل اکسل «کمیسیون فنی»

بازطراحی کامل یک کارپوشهٔ مالی فارسی (RTL، ریال، تقویم شمسی) — از صفر، در ساختار، ظاهر و
تجربهٔ کاربری — با حفظ **دقیق** تمام فرمول‌ها و منطق محاسباتی فایل مبدأ.

## ساختار مخزن

| مسیر | توضیح |
|---|---|
| `docs/design-blueprint.md` | نقشهٔ طراحی: شیت‌ها، منطق محاسباتی، سیستم بصری و قابلیت‌های پیشرفته |
| `tools/inspect_workbook.py` | استخراج کامل منطق فایل مبدأ (فرمول‌ها، نام‌های محدوده، اعتبارسنجی، فرمت شرطی، جداول، نمودارها) |
| `tools/jalali.py` | تبدیل دوطرفهٔ تاریخ میلادی ↔ شمسی برای ساخت شیت «تقویم» |
| `build/` | اسکریپت ساخت کارپوشهٔ نهایی |

## اجرا

```bash
# ۱) نصب وابستگی در پوشهٔ محلی (بدون نیاز به دسترسی ریشه)
pip install --target ./pylibs openpyxl

# ۲) شناخت فایل مبدأ
PYTHONPATH=./pylibs python3 tools/inspect_workbook.py <file.xlsx> --json reports/src.json --out reports/src.txt

# ۳) صحت‌سنجی تبدیل تاریخ
python3 tools/jalali.py

# ۴) ساخت فایل نهایی
PYTHONPATH=./pylibs python3 build/build_workbook.py --out "کمیسیون_فنی.xlsx"
```
