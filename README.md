# داشبورد قراردادهای مهر خلیج فارس — نسخهٔ دسکتاپ (PyQt5)

تبدیل برنامهٔ Flask (`mehr_optimized.py` + `dashboard.html`) به یک **برنامهٔ دسکتاپ تک‌فایلی** با
**PyQt5**. دیگر نه Flask لازم است، نه مرورگر، نه فایل HTML و نه فایل CSS/JS.

> فایل اصلی برنامه: **`mehr_dashboard_qt.py`** — همهٔ کد رابط کاربری، نمودارها، آیکون‌ها،
> خروجی‌ها و خواندن اکسل داخل همین یک فایل هستند.

---

## ۱) نصب و اجرا

```bash
pip install PyQt5 openpyxl
python mehr_dashboard_qt.py
```

اگر فایل اکسل کنار اسکریپت نباشد، پنجرهٔ «انتخاب فایل اکسل» باز می‌شود. می‌توانید مسیر را
از خط فرمان هم بدهید:

```bash
python mehr_dashboard_qt.py --excel "D:\...\F.O.C(Mehr).xlsx" --pdf-folder "D:\...\PDF-MEHR"
```

گزینه‌های دیگر:

| گزینه | کاربرد |
|---|---|
| `--excel PATH` | مسیر فایل اکسل (بر تنظیمات ذخیره‌شده اولویت دارد) |
| `--sheet NAME` | نام شیت (پیش‌فرض `colorcode`) |
| `--pdf-folder PATH` | پوشهٔ فایل‌های PDF قراردادها |
| `--theme light\|dark` | پوستهٔ برنامه |
| `--check` | فقط خواندن اکسل و نمایش آمار در کنسول (بدون باز کردن پنجره) — برای عیب‌یابی |

نمونهٔ بررسی سریع:

```bash
python mehr_dashboard_qt.py --check --excel "F.O.C(Mehr).xlsx" --pdf-folder "PDF-MEHR"
```

## ۲) چه چیزی به چه چیزی تبدیل شد؟

| نسخهٔ وب (Flask) | نسخهٔ دسکتاپ (PyQt5) |
|---|---|
| `app.run(...)` و صفحه در مرورگر | پنجرهٔ بومی Qt |
| `dashboard.html` + Jinja2 (`{% for %}`, `{{ }}`) | ویجت‌های بومی Qt (کارت، جدول، نمودار) |
| `bootstrap.rtl.min.css` / `Vazirmatn` / `bootstrap-icons` | QSS داخلی + آیکون‌های برداری + فونت سیستم/فونت کنار برنامه |
| `Chart.js` (نمودار دونات و میله‌ای) | نمودارهای سفارشی `QPainter` با همان رنگ‌ها و رفتار کلیک |
| `pandas.read_excel(..., header=None)` | `openpyxl` با همان ایندکس ستون‌ها (بدون نیاز به pandas) |
| کارت‌های آماری با `data-filter` | کارت‌های قابل کلیک که جدول را فیلتر می‌کنند |
| جستجوی `smartSearch` در مرورگر | کادر جستجو در نوار بالا + جستجوی جدول |
| `XLSX.writeFile` (SheetJS) | خروجی اکسل واقعی با `openpyxl` (با انتخاب ستون و دامنه) |
| `/export/management_report` | «گزارش مدیریتی» با خروجی اکسل سه‌شیتی و چاپ/PDF |
| لینک `/pdf_mehr/<file>` + رمز PDF | ستون «فایل»، کتابخانهٔ PDF و باز کردن با برنامهٔ پیش‌فرض |
| پنل جزئیات و یادداشت سمت راست | پنل «جزئیات قرارداد» با یادداشت، پیگیری و نشان‌گذاری (ذخیرهٔ محلی) |
| `/api/ollama-chat` (هوش مصنوعی) | حذف شده — نیازمند سرور محلی Ollama بود |
| رمز ورود `1524` و کاربران شبکه | حذف شده — برنامهٔ دسکتاپ تک‌کاربره است |

### شماره‌ستون‌هایی که دقیقاً مثل نسخهٔ وب خوانده می‌شوند

شیت `colorcode`، داده‌ها از ردیف ۴ به بعد (سرستون‌ها در ردیف ۳):

| مقدار | محل در اکسل |
|---|---|
| درصد پیشرفت کل | ردیف ۲، ستون ۳۷ |
| عنوان ستون‌های کسورات | ردیف ۳، ستون‌های ۱۲ تا ۳۴ |
| ردیف/نام/شماره/موضوع قرارداد | ستون‌های ۱، ۴، ۵، ۷ |
| نوع قرارداد | ستون ۶ |
| پرچم‌های M (۸ وضعیت) | ستون‌های ۱۲، ۱۳، ۱۷، ۲۲، ۲۴، ۲۵، ۲۹، ۳۱ |
| پیشرفت جدول / درصد اختتام جدول | ستون‌های ۱۱ و ۳۷ |
| وضعیت پکیج آزادسازی | ستون ۴۵ |
| پیشرفت کارکرد / اختتام / الحاقیه | ستون‌های ۵۴، ۵۵، ۵۶ |
| ستون‌های AW / AX / AY | ستون‌های ۴۸، ۴۹، ۵۰ |

تبدیل کدهای عددی (۱ تا ۵ برای پیشرفت، ۱ تا ۴ برای اختتام، `A` تا `G` برای الحاقیه) و
منطق «کسورات = جمع عنوان ستون‌هایی که مقدار `M` دارند» عیناً از نسخهٔ وب منتقل شده است.

## ۳) امکانات برنامه

- **داشبورد**: پیشرفت کل، ۱۰ کارت آماری، نمودار پکیج آزادسازی، الحاقیه، نوع قرارداد،
  پیشرفت کارکرد، پیشرفت اختتام، ۱۰ نوع پرتکرار و پیش‌نمایش قراردادها.
- **فیلتر با کلیک**: روی کارت‌ها، برش‌های نمودار یا میله‌های نمودار کلیک کنید تا جدول فیلتر شود.
- **جدول قراردادها**: جستجو (چند کلمه‌ای)، فیلتر، مرتب‌سازی با کلیک روی سرستون،
  نمایش/مخفی‌کردن ستون‌ها، انتخاب چند ردیف و منوی راست‌کلیک.
- **جزئیات قرارداد**: دوبار کلیک روی هر ردیف؛ شامل همهٔ وضعیت‌ها، کسورات، فایل PDF،
  یادداشت با تاریخ شمسی و پیگیری، و نشان‌گذاری.
- **خروجی اکسل**: انتخاب ستون‌ها و دامنه (نمایان / انتخاب‌شده / همه).
- **گزارش مدیریتی**: پیش‌نمایش + خروجی اکسل (خلاصه، نیازمند پیگیری، توزیع‌ها) + چاپ/PDF.
- **کتابخانهٔ PDF**: فهرست فایل‌های پوشهٔ PDF با جستجو.
- **پوستهٔ روشن/تیره** و **بازخوانی خودکار** (پیش‌فرض هر ۵ دقیقه، فقط اگر زمان تغییر فایل عوض شود).
- **Drag & Drop**: فایل اکسل را روی پنجره رها کنید.

### میان‌برها

| کلید | کار |
|---|---|
| `Ctrl+R` | بازخوانی اکسل |
| `Ctrl+F` | جستجو |
| `Ctrl+E` | خروجی اکسل جدول |
| `Ctrl+D` | تغییر پوسته |
| `Ctrl+I` | پنل جزئیات |
| `F1` | راهنما |
| `Esc` | بستن پنل / بازگشت |

## ۴) فایل‌های ذخیره‌شده

- `mehr_qt_config.json` — مسیر اکسل/PDF، پوسته، اندازهٔ قلم، بازخوانی خودکار، ابعاد پنجره.
- `mehr_notes.json` — یادداشت‌ها، تاریخ پیگیری و نشان‌ها.

این دو فایل کنار برنامه ساخته می‌شوند؛ اگر پوشهٔ برنامه قابل نوشتن نباشد، در
`~/.mehr_dashboard/` ساخته می‌شوند. مسیر دقیق در «تنظیمات» نمایش داده می‌شود.

---

## ۵) ساخت فایل EXE (اختیاری)

کل برنامه در یک فایل `mehr_dashboard_qt.py` است. اگر می‌خواهید روی سیستم‌هایی که پایتون
ندارند هم اجرا شود، با PyInstaller یک فایل اجرایی تک‌فایلی بسازید:

**ویندوز:** روی `build_exe_windows.bat` دوبار کلیک کنید (یا در CMD اجرا کنید).
**لینوکس:** `bash build_linux.sh`

خروجی: `dist/MehrDashboard.exe` (ویندوز) یا `dist/MehrDashboard` (لینوکس) — تک‌فایل و بدون کنسول.
مسیر اکسل را بعد از اجرا از «تنظیمات» انتخاب کنید. فونت فارسی دلخواه (مثلاً
`Vazirmatn-Regular.ttf`) را هم می‌توانید کنار برنامه یا در پوشهٔ `fonts` بگذارید؛ برنامه
خودش آن را بارگذاری می‌کند.

> فایل‌های `mehr_qt_config.json` و `mehr_notes.json` هنگام اجرا در کنار برنامه (یا اگر
> پوشه قابل نوشتن نبود، در `~/.mehr_dashboard/`) ساخته می‌شوند.

اگر شکل‌دهی عدد/متن فارسی در ویندوز قدیمی مشکل داشت، نصب فونت **Vazirmatn** توصیه می‌شود.

## ۶) عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| «فایل اکسل پیدا نشد» | مسیر را در «تنظیمات» انتخاب کنید یا `--excel` بدهید |
| «شیت colorcode پیدا نشد» | نام شیت را در تنظیمات تغییر دهید (نام‌ها در پیام خطا نمایش داده می‌شود) |
| ستون «فایل» خالی است | پوشهٔ PDF را تنظیم کنید؛ نام فایل باید با شمارهٔ قرارداد هم‌خوان باشد |
| فونت فارسی زیبا نیست | فونت `Vazirmatn` را نصب یا کنار برنامه کپی کنید |
| خطای `libGL.so.1` در لینوکس | `apt install libgl1 libegl1` |
| خطاهای غیرمنتظره | فایل `mehr_error.log` کنار برنامه را ببینید |
| بررسی سریع داده‌ها | `python mehr_dashboard_qt.py --check --excel ...` |

## ۷) تفاوت‌های عمدی با نسخهٔ وب

1. احراز هویت و مدیریت کاربران شبکه حذف شده‌اند (برنامهٔ تک‌کاربرهٔ دسکتاپ).
2. گفتگوی هوش مصنوعی (Ollama) حذف شده است؛ بقیهٔ منطق بدون تغییر مانده است.
3. تنظیمات و یادداشت‌ها در فایل JSON محلی ذخیره می‌شوند (به‌جای local storage مرورگر).
4. نوشتن در اکسل (به‌روزرسانی وضعیت، آپلود اکسل) عمداً پیاده‌سازی نشده تا فایل اصلی
   به‌طور ناخواسته تغییر نکند؛ خروجی‌ها همیشه در فایل جدید ذخیره می‌شوند.
